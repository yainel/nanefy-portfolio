PreguntasQuestions

Lo que suelen preguntarWhat people usually ask

¿Tengo que cambiar de sistema?Do I have to change systems?

No. Nanefy lee los productos y precios de LOC SMS; la tienda sigue cobrando y cambiando precios en LOC SMS como siempre.No. Nanefy reads products and prices from LOC SMS; the store keeps ringing up and changing prices in LOC SMS as always.

¿Qué equipo necesito?What hardware do I need?

Para las etiquetas, una impresora normal o térmica. Para el verificador, una tableta o quiosco con Chrome. Para las pantallas, cualquier TV con navegador. El mapa se abre en el teléfono del cliente.For labels, a regular or thermal printer. For the price checker, a tablet or kiosk with Chrome. For screens, any TV with a browser. The map opens on the shopper's phone.

¿Puedo empezar con un solo módulo?Can I start with one module?

Sí. Cada módulo se contrata por separado y se puede agregar o quitar cuando quiera.Yes. Each module is billed on its own and can be added or removed whenever you like.

¿Funciona en español?Does it work in Spanish?

Sí. Cada usuario elige español o inglés, y las páginas para clientes, como el mapa, también.Yes. Every user picks Spanish or English, and so do the shopper pages, like the map.

¿Sirve para varias tiendas?Does it work for several stores?

Sí. Cada tienda tiene su portal, y las plantillas y temas se pueden compartir entre las tiendas de un grupo.Yes. Each store has its own portal, and templates and themes can be shared across the stores of a group.
